CARA PAKAI QRIS
===============

Letakkan file gambar QRIS asli di folder ini dengan format nama:

  qris_{JUMLAH}.png

Contoh:
  qris_600000.png    → untuk pembayaran Rp 600.000
  qris_750000.png    → untuk pembayaran Rp 750.000
  qris_900000.png    → untuk pembayaran Rp 900.000
  qris_1200000.png   → untuk pembayaran Rp 1.200.000
  qris_1500000.png   → untuk pembayaran Rp 1.500.000
  qris_2000000.png   → untuk pembayaran Rp 2.000.000
  qris_2100000.png   → untuk pembayaran Rp 2.100.000
  qris_2500000.png   → untuk pembayaran Rp 2.500.000
  qris_2700000.png   → untuk pembayaran Rp 2.700.000
  qris_3000000.png   → untuk pembayaran Rp 3.000.000
  qris_3600000.png   → untuk pembayaran Rp 3.600.000
  qris_4000000.png   → untuk pembayaran Rp 4.000.000
  qris_7000000.png   → untuk pembayaran Rp 7.000.000
  qris_9000000.png   → untuk pembayaran Rp 9.000.000

Format yang didukung: .png, .jpg, .jpeg, .webp

Jumlah diambil dari termin yang harus dibayar, misalnya:
- Paket Rp 3.000.000 → Termin 1 (30%) = Rp 900.000 → butuh qris_900000.png
- Paket Rp 3.000.000 → Termin 2 (70%) = Rp 2.100.000 → butuh qris_2100000.png

Jika file QRIS tidak ditemukan, sistem akan generate QR code otomatis (dummy).
